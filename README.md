## 👋 Hello Everyone!

I'm excited to share my **Hotel Booking Automation Testing** project! 🎯

This project focused on building a **structured, maintainable, and scalable automation framework** for a hotel booking application, going beyond simply automating individual test cases into real framework design.

> 💡 *Through this experience, I strengthened my understanding of test case analysis, automation strategy, and reusable framework development — core skills for modern QA engineering.*

---

## 📌 Project Overview

This project demonstrates a **Selenium WebDriver automation framework** built with **C#, TestNG, and the Page Object Model**, applied to a real-world **hotel booking application**.

The framework covers identifying and implementing positive, negative, and functional test scenarios for key hotel application functionalities, with an emphasis on clean architecture, reusable components, and detailed execution reporting.

---

## 🏗️ Key Features Implemented

<div align="center">

| 🔹 Feature | 📘 Description |
|:-:|:-|
| 🗂️ Page Object Model (POM) | Clean separation between test logic and page locators/actions · Easier maintenance & reuse |
| 🧪 Test Case Identification | Analysed application functionality · Positive, negative & functional scenario coverage |
| ⚙️ TestNG Framework | Annotations · Assertions · Grouping · Structured test management |
| 📋 Extent Reports | Detailed, visual execution reports · Test status & execution information |
| 🧱 Hierarchical Framework Structure | Proper hierarchy & reusable components · Improved organisation & scalability |
| 🔁 Reusable Utilities & Components | Shared methods to reduce duplication · More efficient test scripts |
